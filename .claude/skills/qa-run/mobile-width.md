# Мобільна ширина: як її взагалі отримати

Довідка до `qa-run`. Читати, коли треба перевірити мобільну верстку, а device
mode не відкривається — не на кожен прогін.

DevTools із Claude in Chrome не відкриваються: тулзи працюють усередині документа,
а панель пристроїв — це вікно браузера. `resize_window` теж не діє, коли вікно
розгорнуте на весь екран.

**Перший крок — просто попросити Ярослава.** Він ввімкне device mode (Ctrl+Shift+M)
або виставить потрібну ширину вікна за секунди, і далі сторінка сама віддає
`innerWidth` 390 і мобільні медіазапити — тестування виходить чесним і якісним.
Не мовчати, не писати «не вдалося перевірити» і не задовольнятись гіршим обхідним
шляхом: сказати, яка саме ширина потрібна, і дочекатися.

**Другий повноцінний шлях — Claude Code Desktop.** У десктопному застосунку на Windows
працює computer use: Claude керує самим вікном браузера, а не лише вмістом документа —
тобто може натиснути `Ctrl+Shift+M`, вибрати пристрій зі списку, виставити ширину
вікна. У CLI цього немає (там computer use лише на macOS), тому з термінала цей шлях
недоступний. Якщо мобільна перевірка потрібна регулярно, а не разово, це варто
запропонувати Ярославу: `/desktop` переносить поточну сесію в застосунок, computer use
вмикається в **Settings → General → Desktop app**, і далі кожен застосунок треба
дозволити окремо на сесію.

Те саме закриває й Firefox з Opera: їхні вікна — це теж GUI, до якого розширення
Chrome не дотягується, а computer use дотягується.

Обхідні варіанти — тільки якщо Ярослава нема на місці, а десктопом не користуємось:

1. **Через `iframe`** — медіазапити рахуються від ширини фрейма, а не вікна:
   вставити в сторінку `iframe` шириною 390-414 px із тим самим URL (той самий
   origin — `contentDocument` доступний), дочекатися `load` і працювати всередині.
   Мінус: скріншот буде дрібним, а сам фрейм — не справжній мобільний в'юпорт
   (немає dpr, тач-подій, мобільного UA).
2. Згорнути вікно з максимуму — тоді `resize_window` починає працювати.

Скріншот мобільного екрана виходить фізично дрібним — знімається стільки пікселів,
скільки має вікно. Для доказу цього достатньо, але не розтягуй його у звіті на всю
ширину: обмеж `max-width` близько 300-430 px, інакше він розмиється.
